Macro Tracker — PWA

A private, local-first food and macro tracker.

GitHub Pages deployment
1. Upload all files in this package to the repository root.
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main and /(root), then Save.
5. Open the resulting GitHub Pages URL.

Phone installation
- Android/Chrome: browser menu > Install app / Add to Home screen.
- iPhone/iPad: Safari > Share > Add to Home Screen.

Data
Food library, history, goals, and preferences are stored locally in that browser/app.
Use the app's JSON export/import for backups and transfers.
